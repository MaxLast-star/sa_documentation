# Стратегия платформизации

## Что можно заменить готовым решением

### Модуль визуализации (BI-дашборды)
Базовые дашборды (динамика качества, отклонения по линиям) можно реализовать через готовые решения — **PowerBI, Metabase, Grafana** — подключив их напрямую к БД. Это исключает необходимость разработки собственного frontend на MVP.

### Модуль генерации текстовых отчётов
Вместо собственной LLM можно использовать готовые API — **Claude, ChatGPT, Gemini** — передавая в них контекст из производственной БД. Это позволяет:
- Генерировать отчёты по заданным шаблонам (через системные промпты)
- Интерпретировать числовые показатели
- Объяснять аббревиатуры через RAG по внутреннему глоссарию

## Что нельзя заменить готовым решением

| Модуль | Причина уникальности |
|--------|---------------------|
| ИИ-чат с производственным контекстом | Общедоступные чаты не знают специфику предприятия; уникальность через RAG и дообучение |
| Предикативная аналитика | Математические и физические модели специфичны для конкретных технологических процессов |
| Интеграции с MES/ERP/датчиками | Коннекторы к отдельным системам (1С, SAP, MES) требуют разработки под каждого клиента |

## Схема интеграции с Anthropic Claude API

```
Пользователь → чат-интерфейс
    ↓
Backend формирует промпт:
  [данные из БД] + [шаблон] + [запрос пользователя]
    ↓
Claude API (облако)
    ↓
Текстовый ответ / готовая справка
    ↓
Отображение в UI
```

**Преимущества:** нет необходимости обучать собственную модель; быстрая интеграция (1–2 недели vs 2–3 месяца).  
**Риски:** производственные данные передаются во внешний контур → требуется корпоративное соглашение конфиденциальности.

## Целевые сегменты

**Приоритетный:** металлургия — высокая стоимость брака, строгие требования сертификации.

**Перспективные:**
- Машиностроение и приборостроение
- Химическая и нефтехимическая промышленность
- Пищевая промышленность
- Фармацевтика

**Принцип платформизации:** ядро системы (сбор данных, ИИ-анализ, справки) остаётся неизменным. Шаблоны, метрики и коннекторы настраиваются под каждый сегмент.

## Модель монетизации

**Модель:** разовая лицензия + платная поддержка и обновления  
**Целевой покупатель:** промышленное предприятие (B2B)

| Статья | Описание | Ориентировочная стоимость |
|--------|----------|---------------------------|
| Лицензия базовая | Право использования на серверах клиента | 1,5–3 млн ₽ |
| Лицензия продвинутая | + предиктивная аналитика и полные интеграции | 4–8 млн ₽ |
| Внедрение и настройка | Интеграции, обучение, шаблоны | 500 тыс.–2 млн ₽ |
| Техническая поддержка | SLA, исправление ошибок, горячая линия | 15–20% от лицензии/год |
| Обновления | Доступ к новым версиям | 20–30% от лицензии/год |

**Дополнительные услуги:** кастомные шаблоны справок, обучение пользователей, индивидуальное дообучение ИИ.
