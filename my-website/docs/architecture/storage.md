# Технологии хранения данных

## Сущности системы

| Сущность | Атрибуты | Описание |
|----------|----------|----------|
| Пользователь | id, fullName, role, password, email, login | Учётные записи сотрудников |
| Чат | id, name, createdAt, createdBy | Диалог с ИИ |
| Сообщение | id, chatId, sender, timestamp, content | Сообщение в чате |
| Справка | id, templateID, title, createdAt, createdBy, status | Сгенерированный отчёт |
| Шаблон справки | id, name, parameters, description, body | Шаблон для генерации |
| Данные датчиков | id, equipmentId, timestamp, parameterName, parameterValue, unit | Технологические параметры |
| Лог системы | id, timestamp, level, source, message, userId | Логи ошибок и событий |

## Итоговое решение

| Сущность | Тип хранилища | Обоснование |
|----------|---------------|-------------|
| Пользователь | Реляционная СУБД | Малый объём, ACID, простые запросы |
| Чат | Elasticsearch + Реляционная СУБД | Полнотекстовый поиск |
| Сообщение | Реляционная СУБД | Простые запросы |
| Справка | Реляционная СУБД + Object Storage | ACID и фильтрация; body содержит медиа-объекты |
| Шаблон | Реляционная СУБД с JSON | Гибкая схема (разные шаблоны — разная структура) |
| Данные датчиков | Time-Series DB | Высокая скорость записи, запросы по времени |
| Лог системы | Elasticsearch | Поиск по логам, фильтрация по времени/уровню/источнику |
