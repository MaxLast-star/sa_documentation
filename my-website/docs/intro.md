# Система мониторинга качества металлопродукции

## Описание продукта

Платформа для мониторинга качества продукции на металлургическом предприятии. Собирает данные и производственные метрики из разных систем (MES, ERP, датчики), анализирует их и автоматически формирует справки с прогнозами.

**Ключевая ценность:** рост качества продукции, ускорение аналитических процессов, снижение ручного труда.

## Проблемы, которые решает система

- Данные разрознены между MES, ERP, Excel и журналами — нет единого источника
- Значительная часть анализа делается вручную, высок риск ошибки
- Нет инструментов предупреждения о рисках ухудшения качества
- Нет единого подхода к формированию справок и отчётов
- При текучке кадров теряется накопленный опыт

## Целевая аудитория

| Сегмент | Потребность |
|---------|-------------|
| Инженеры качества | Точность данных, предиктивная аналитика |
| Инженеры АСУ ТП | Мониторинг сигналов, ранние предупреждения |
| Технологи участков | Рекомендации по поддержанию оптимальных режимов |
| Аналитики предприятия | Точные данные, инструменты анализа |
| Руководители подразделения качества | Визуализации, прогнозы, сводные отчёты |

## Ключевые функции (MVP)

- Сбор данных из 2–3 источников (MES, ERP, БД)
- Чат с ИИ-агентом для работы с производственными данными
- Генерация справок по шаблонам
- Аналитика отклонений
- Дашборды на основе актуальных данных

## Бизнес-цели (SMART)

- Улучшить качество продукции на **10%** за 6 месяцев
- Сократить время формирования справок с 120 до **10 минут** за 4 месяца
- Уменьшить количество ручных операций на **70%** за 6 месяцев
- Сократить время реакции на отклонения с 5 часов до **30 минут** за 4 месяца

## Версии продукта

| Версия | Содержание | Срок |
|--------|------------|------|
| **MVP 1.0** | Сбор данных, дашборды, справки, ИИ-агент | 3–4 месяца |
| **2.0** | Предикативная аналитика, анализ причин, интеграция MES/ERP | +3 месяца |
| **3.0** | Автоматизация решений, мобильный интерфейс, полный цикл управления качеством | 12 месяцев |
